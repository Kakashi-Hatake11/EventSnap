EventSnap is a seamless event photography platform built entirely in Kotlin using Jetpack Compose and Firebase. It eliminates the hassle of scrolling through thousands of event photos. Photographers can easily bulk-upload high-resolution images via a background worker, and guests can simply scan an event QR code, snap a quick selfie, and instantly receive a curated gallery of every photo they appear in.
EventSnap
A native Android application that revolutionizes event photo sharing.
Built with a modern MVVM architecture, Jetpack Compose, and Dagger Hilt.
Integrates Firebase Auth, Firestore, and Cloud Storage for real-time synchronization across Admin, Photographer, and Guest roles.
Features on-device background image compression via Android WorkManager and automated photo-matching workflows.
